# SQL histórico de reclutamiento

`reclutamiento_01_postulaciones.sql.txt` conserva la versión local anterior del esquema, como referencia. No debe ejecutarse ni sustituir las migraciones vigentes: usa estados en minúsculas y una tabla de CV distinta de la que consume la bandeja actual.

La instalación vigente usa `supabase/reclutamiento_01_solicitudes.sql`. La corrección adicional de columnas de entrevista se conserva en `supabase/reclutamiento_02_columnas_entrevista.sql` y no reemplaza las funciones ni los CV existentes.
