# KJA-035 — retirar chat/notificaciones y hacer pausas locales

Estado: REVISAR. Corte: 10/11/2026. Implementación frontend y SQL preparados; publicación y aplicación remota se acreditan por separado.

## Objetivo y decisiones

Retirar chat y bandeja para todos los roles, eliminar sus accesos y consultas y quitar informes administrativos de pausas. Conservar el historial privado y los adjuntos. Pausas de 20/10 minutos libres, con continuidad local por cuenta, sin backend ni registro laboral. Decisiones confirmadas con Piero mediante grill-me; el corte SQL requiere revisión concreta antes de ejecutarlo.
